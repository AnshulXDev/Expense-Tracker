# 🧾 Expense Tracker (Python)

A simple and beginner-friendly **Expense Tracker** made using Python.  
This project allows you to add expenses, view expense history, and calculate the total amount spent.

---

## 🚀 Features
- Add new expense with **item name** and **amount**
- Automatically stores each expense in a list
- Displays all expenses in a clean format
- Shows **total money spent**
- Runs continuously until you choose to exit (interactive loop)

---

## 📌 How It Works
The program uses:
- **List of dictionaries** to store expenses  
  ```python
  expenses = [{"item": "Tea", "amount": 10}]
  ```

---  

## ▶️ How to run
- Install **Python (3.10+ recommended)**
- Run the script:
```bash
python main.py
```
